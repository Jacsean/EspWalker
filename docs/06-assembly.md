# 06 · 装配作业指导书

> 适用：Esp32Walker 模块拼装原型，默认**两轮差速底盘**（固件 `CONFIG_APP_CHASSIS_TYPE="diff2"`）+ 超声避障；摄像头/语音为可选模块。麦轮四轮底盘见 §6 附注。

## 1. 目的与范围

本文规范从零散物料到「通电前完整整机」的装配作业，使装配结果可通电、可调试。装配完成判据见 §7 自检清单。

## 2. 安全须知

1. **断电作业**：所有接线、插拔在断电状态下进行。
2. **先低压后高压**：先接 3.3V/5V 逻辑电源与信号线，最后接电机电源 VM。
3. **极性核对**：VCC/GND 不得接反；电机驱动 VM/VCC 接错会烧模块。
4. **防短路**：裸线端、焊点加热缩管或绝缘胶，避免相邻引脚搭接。

## 3. 工具与物料准备

| 类别 | 内容 |
|---|---|
| 工具 | 十字/一字螺丝刀、烙铁 + 焊锡、斜口钳、剥线钳、镊子、万用表 |
| 耗材 | 杜邦线（公母/母母）、22AWG 硅胶线（电机）、双绞线、热缩管、尼龙扎带 |
| 结构 | 亚克力/3D 打印底盘板、M3 铜柱 ×4~8、M3 螺丝螺母 |
| 物料 | 按 `docs/05-bom.md` 清单备齐 |

## 4. 装配步骤

### 阶段 A：底盘装配（两轮差速）

| 步骤 | 操作 | 要点 / 验收 |
|---|---|---|
| A1 | 将 2 个 N20 电机装入底盘电机座（左右对称） | 电机轴伸出，紧固不晃动 |
| A2 | 压入左右驱动轮（橡胶轮） | 轮与轴同轴，转动无卡滞 |
| A3 | 安装万向轮（牛眼轮）于前端或后端 | 使底盘三点着地、水平 |
| A4 | 用铜柱架起上层板（放主控/驱动/传感器） | 上层板水平、无干涉 |
| A5 | 走线：电机 2 根线引到上层板驱动区，双绞 | 留 10 cm 余量，避开轮子 |

### 阶段 B：电机驱动接线

按「一块 TB6612 带两个电机」接线（默认 2 电机只用 1 块 TB6612）：

| TB6612 引脚 | 接法（左=电机1，右=电机2） |
|---|---|
| PWMA | 主控 GPIO 4 |
| AIN1 / AIN2 | 主控 GPIO 8 / GPIO 9 |
| A01 / A02 | 左电机 M+/M− |
| PWMB | 主控 GPIO 5 |
| BIN1 / BIN2 | 主控 GPIO 10 / GPIO 11 |
| B01 / B02 | 右电机 M+/M− |
| VM | 电机电源 5 V（方案 A） |
| VCC | 主控 3.3 V |
| STBY | 主控 3.3 V（常使能） |
| GND | 与主控 GND 共地 |

⚠️ 电机 M+/M− 暂不分正反，方向错误在调试阶段用 `move` 校正（见 07 §6.4）。

### 阶段 C：传感器 / 音频 / 摄像头接线

| 模块 | 模块引脚 | 主控引脚 | 供电 | 备注 |
|---|---|---|---|---|
| 超声波 HC-SR04 | Trig / Echo | GPIO 16 / GPIO 17 | 5 V | GND 共地 |
| TOF VL53L0X（可选） | SDA / SCL | GPIO 41 / GPIO 42 | 3.3 V | 默认 1 颗，地址 0x29 |
| 麦克风 INMP441 | WS / SCK / SD | GPIO 2 / GPIO 3 / GPIO 46 | 3.3 V | **L/R 脚接 GND** |
| 功放 MAX98357A | BCLK / LRC / DIN | GPIO 18 / GPIO 19 / GPIO 20 | 5 V | SD 悬空/接高，GAIN 按需 |
| 喇叭 | + / − | 功放 SPK+ / SPK− | — | 3W/4Ω |
| 摄像头 OV2640/OV3660 | DVP 排线（见 02 §9） | 见 esp32-camera S3 引脚 | 3.3 V | ⚠️ 启用时需重排电机引脚 |
| 拍照按钮 | 一端 GND，另一端 | GPIO 0 | — | 内部上拉，按下=低 |
| 状态 LED | 阳极→限流电阻→GPIO 21 | 阴极→GND | — | 330~1k Ω |

### 阶段 D：电源接线（方案 A，推荐）

| 步骤 | 操作 |
|---|---|
| D1 | 主板 5 V / GND 经 USB 线接 5V/2A 电源 |
| D2 | 电机驱动 VM 接 5 V（与逻辑共源或独立 5V 均可），GND 共地 |
| D3 | 主板 VCC 处并 **100 µF + 0.1 µF** 去耦电容；VM 处同样并联 |
| D4 | 最后接入电机驱动 STBY（3.3V 使能） |

## 5. 接线总表（两轮差速默认）

| 主控 GPIO | 功能 | 去向 |
|---|---|---|
| 4 / 8 / 9 | 电机 1 PWM / AIN1 / AIN2 | TB6612 PWMA / AIN1 / AIN2 |
| 5 / 10 / 11 | 电机 2 PWM / BIN1 / BIN2 | TB6612 PWMB / BIN1 / BIN2 |
| 16 / 17 | 超声 Trig / Echo | HC-SR04 |
| 41 / 42 | I2C SDA / SCL | VL53L0X（可选） |
| 2 / 3 / 46 | 麦克风 WS / SCK / SD | INMP441 |
| 18 / 19 / 20 | 功放 BCLK / LRC / DIN | MAX98357A |
| 0 | 拍照按钮 | 按钮→GND |
| 21 | 状态 LED | LED（串限流电阻） |
| 3.3V / 5V / GND | 供电 | 各模块 VCC / GND |

## 6. 附注：麦轮四轮底盘

四电机用 **2 块 TB6612**，在阶段 B 基础上补充电机 3/4：

| TB6612 引脚 | 接法 |
|---|---|
| 第二块 PWMA / AIN1 / AIN2 | GPIO 6 / 12 / 13 → 前左电机 |
| 第二块 PWMB / BIN1 / BIN2 | GPIO 7 / 14 / 15 → 前右电机 |

四轮顺序（固件约定）：前左 / 前右 / 后左 / 后右，对应 `chassis.c` 的 `w[0..3]`。麦轮有左旋/右旋，装错会打滑——按轮纹斜向朝车体中心的原则装配。

## 7. 装配完成自检清单

- [ ] 目视：无裸线短路、无虚焊、极性无接反
- [ ] 万用表：主控 3.3V 与 GND 无短路；5V 与 GND 无短路（电阻 > 1 kΩ）
- [ ] 共地：所有模块 GND 与主控 GND 导通
- [ ] STBY 已接 3.3V；INMP441 L/R 已接地
- [ ] 电机线双绞、远离摄像头/麦克风走线
- [ ] 轮子转动无卡滞，底盘水平、四脚（三轮）着地
- [ ] 摄像头启用时，电机引脚已按 02 §9 重排且无冲突

通过全部自检项后方可进入 `docs/07-poweron.md` 的通电调试。
