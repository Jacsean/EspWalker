## 2. 主控选型

| 项目 | 选择 | 说明 |
|---|---|---|
| 主控 | **ESP32-S3-DevKitC-1 (N16R8)** | 16 MB Flash + 8 MB PSRAM；双核 240 MHz；Wi-Fi + BLE |
| 备选 | ESP32-S3-WROOM-1-N16R8 模组 + 自制底板 | 量产阶段用 |
| PSRAM | **必须 ≥ 8 MB** | 摄像头帧缓冲依赖 PSRAM，缺 PSRAM 只能拍极低分辨率 |

> 选择 DevKitC-1 的原因：DVP 摄像头接口、I2S、LEDC PWM 引脚齐全，USB-JTAG 烧录调试方便，模块拼装起步成本最低。

## 3. 运动底盘（统一接口 + 三种底座）

### 3.1 统一接口设计

底盘与主控之间只保留两种电气连接，**换底座不换主板、不改软件协议**：

| 信号 | 数量 | 说明 |
|---|---|---|
| 电机驱动线 (M+, M−) | 2 或 4 路 | 接 TB6612 输出，每路一个直流减速电机 |
| 编码器 (A, B, VCC, GND) | 0 / 2 / 4 路 | 可选霍尔/磁编码器，用于里程与闭环 |

软件侧以「底盘类型」参数区分运动学，见 `components/chassis`。

### 3.2 三种底座

| 底座 | 电机数 | 运动学 | 特点 / 适用 |
|---|---|---|---|
| **两轮差速 + 尾轮** | 2 | `vL = v − ω·L/2, vR = v + ω·L/2` | 结构最简单，桌面灵活转向；推荐 N20 减速电机（带编码器 6V） |
| **履带底盘** | 2 | 同两轮差速（驱动两条履带） | 越障、摩擦力好，适合地毯/不平桌面；N20 或 TT 电机 |
| **麦克纳姆轮 / 四轮** | 4 | `vFL = vx − vy − ω(Lx+Ly)` 等（见 §3.3） | 全向移动（横移/斜移），动作最炫；需 4 个麦轮 + 4 电机 |

### 3.3 麦克纳姆轮运动学（参考）

以车体中心为原点，`Lx`、`Ly` 为轮距半轴，`(vx, vy, ω)` 为期望速度：

```
v_FL =  vx - vy - ω*(Lx + Ly)     // 前左
v_FR =  vx + vy + ω*(Lx + Ly)     // 前右
v_RL =  vx + vy - ω*(Lx + Ly)     // 后左
v_RR =  vx - vy + ω*(Lx + Ly)     // 后右
```

两轮/履带只需 `(v, ω)`，忽略 `vy`。

## 4. 电机驱动

| 项目 | 选择 | 说明 |
|---|---|---|
| 驱动芯片 | **TB6612FNG** ×2 | 双路 H 桥；VM 2.5~13.8 V，峰值 1.2 A/路；2 片支持 4 电机 |
| 备选 | DRV8833 | 电流略小（1 A），2 路/片，体积更小 |
| 速度控制 | LEDC PWM（ESP32-S3，4 通道） | 频率 20 kHz，10 bit 分辨率 |
| 方向控制 | 每路 2 个 GPIO（AIN1/AIN2） | 00=刹车，01=正转，10=反转 |

接线要点：`PWMA/PWMB → 主控 PWM 引脚`，`AIN1/AIN2/BIN1/BIN2 → 主控 GPIO`，`STBY 接 3.3V（常使能）`，`VM 接电机电源`，`VCC 接 3.3V`，`GND 与主控共地`。

## 5. 障碍物感知

| 传感器 | 接口 | 量程 / 特点 | 用途 |
|---|---|---|---|
| **VL53L0X 激光 TOF**（推荐） | I2C | 3~200 cm，精度高、刷新快、体积小 | 前向精确测距 |
| HC-SR04 超声波 | GPIO(Trig/Echo) | 2~400 cm，便宜 | 备选 / 多面布置 |
| 微动/碰撞开关 | GPIO | 接触检测 | 机械防撞兜底 |

推荐布局：正前方 1 个 VL53L0X（或 3 个：前左 / 前中 / 前右）+ 两侧碰撞开关。避障判定在 `components/proximity`，本地实时闭环。

### IMU 姿态（推荐，已实现）

| 项目 | 选择 | 说明 |
|---|---|---|
| 传感器 | **MPU6050**（6 轴）/ **MPU9250**（9 轴） | I2C 地址 0x68（AD0 接地），复用 GPIO41/42 |
| 替代 | ICM-42688-P / ICM-20948 | 低噪声、SPI，多旋翼飞行常用 |
| 用途 | 航向/姿态估计、翻倒检测保护 | 地面模式即受益，飞行模式复用同一颗 |

> 默认启用（`CONFIG_APP_ENABLE_IMU=y`）。固件 `components/imu` 读取 6 轴数据，互补滤波解算 roll/pitch/yaw，姿态随 `status` 上报；roll 或 pitch 绝对值超过 60° 时自动停车防翻倒。

## 6. 摄像头

| 项目 | 选择 | 说明 |
|---|---|---|
| 模组 | **OV2640**（200 万）/ **OV3660**（300 万） | 均为 DVP 接口、引脚一致，esp32-camera 自动探测 sensor，两种通用 |
| 分辨率 | OV2640：1600×1200；OV3660：2048×1536 | 固件默认 1024×768（两者均稳），选 OV3660 时可用 1600×1200 |
| 组件 | `espressif/esp32-camera` | 拍照 + JPEG 编码，经 Wi-Fi 上传；需在 menuconfig 启用 OV2640/OV3660 支持 |
| 存储 | JPEG 写入 PSRAM 缓冲后立即发送 | 不落卡（如需落卡，加 SD 卡模块） |

拍照触发：物理按钮（短按）/ 中心端指令 / 定时抓拍。

## 7. 语音

| 部件 | 选择 | 接口 | 说明 |
|---|---|---|---|
| 麦克风 | **INMP441** | I2S（WS/SCK/SD） | 数字麦克风，信噪比高、接线简单 |
| 功放 | **MAX98357A** | I2S（BCLK/LRC/DIN） | D 类功放，直驱 3~4 Ω 喇叭 |
| 喇叭 | 3 W / 4 Ω 小口径 | — | 桌面音量足够 |
| 唤醒词 | ESP-SR（WakeNet，本地） | — | 可选组件，命中后开始上传音频 |

> INMP441 与 MAX98357A 可共享一组 I2S 时钟（WS/BCLK），但为减少引脚约束与时钟分频冲突，本方案给两组独立 I2S 引脚。

## 8. 电源方案

| 电源 | 说明 |
|---|---|
| **方案 A（推荐，桌面常供电）**：USB 5 V / 2 A 供主板；电机 VM 由同一 5 V 供电（TB6612 支持 VM=5V） | 最简单，无电池 |
| 方案 B：2×18650（7.4 V）供电机 VM；7.4 V → 5 V 降压（供摄像头/外围）→ 3.3 V LDO（供 ESP32） | 可移动，需充电管理 |

注意事项：电机与逻辑必须**共地**；电机电源加 **100 µF + 0.1 µF** 去耦；Wi-Fi 发射瞬间电流大，主板用短粗线并加 100 µF 电容防 brownout。

| 电机 1 PWM（PWMA） | GPIO 4 | LEDC 通道 0 |
| 电机 2 PWM（PWMB） | GPIO 5 | LEDC 通道 1 |
| 电机 3 PWM | GPIO 6 | 四轮/麦轮用，LEDC 通道 2 |
| 电机 4 PWM | GPIO 7 | 四轮/麦轮用，LEDC 通道 3 |
| 电机方向 AIN1/AIN2 | GPIO 8 / 9 | 电机 1 |
| 电机方向 BIN1/BIN2 | GPIO 10 / 11 | 电机 2 |

| 超声波 Trig / Echo | GPIO 16 / 17 | 可选感知 |
| I2C SDA / SCL | GPIO 41 / 42 | TOF / IMU 共用总线 |
| 麦克风 INMP441 WS / SCK / SD | GPIO 2 / 3 / 46 | I2S 录音 |
| 功放 MAX98357A BCLK / LRC / DIN | GPIO 18 / 19 / 20 | I2S 放音（可选） |

## 11. 装配与接线注意事项

1. **共地**：电机驱动、传感器、摄像头、音频模块的 GND 必须与主控 GND 相连。
2. **电机干扰**：电机电源与逻辑电源分开走线，电机线用双绞线，必要时在电机两端加 0.1 µF 瓷片电容吸收反电动势。
3. **上电顺序**：先接逻辑电源（主控启动），再使能电机驱动（STBY），避免上电瞬间电机抖动。
4. **摄像头排线**：DVP 排线短（≤15 cm），远离电机线，否则图像出现噪点。
5. **烧录**：S3 用 USB-JTAG 口烧录（`idf.py -p COMx flash`），若识别为原生 USB JTAG 无需手动按 BOOT。
