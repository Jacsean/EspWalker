## 2. 详细清单与可替代硬件

### 2.1 主控板

| 项 | 型号 | 说明 |
|---|---|---|
| 主选 | **ESP32-S3-DevKitC-1 (N16R8)** | 16 MB Flash + 8 MB PSRAM，USB-JTAG，引脚齐全 |
| 替代 | ESP32-S3-DevKitM-1 (N16R8) | 体积更小，引脚为排针可上洞洞板 |
| 替代 | ESP32-S3-WROOM-1-N16R8 模组 + 底板 | 量产/一体化，需自制或购买底板 |
| 替代 | Waveshare / Freenove / 合宙 S3 板 | ⚠️ 引脚定义不同，需重排 `board.h` 映射 |

**硬性要求**：必须带 **≥8 MB PSRAM**（摄像头帧缓冲依赖）；无 PSRAM 的 S3 板不能用于拍照。

### 2.2 电机驱动

| 项 | 型号 | 说明 |
|---|---|---|
| 主选 | **TB6612FNG 模块** ×2 | 双路 H 桥，VM 2.5~13.8 V，峰值 1.2 A/路 |
| 替代 | DRV8833 模块 | 电流略小（1 A），体积更小，引脚少 1 个方向脚 |
| 替代 | MX1508 | 小电流（<1 A），仅适合小 N20 |
| 不推荐 | L298N | 压降大、体积大，桌面小机器人不划算 |

⚠️ 注意：TB6612 模块需带 **STBY** 引脚（接 3.3V 使能）；DRV8833 无 STBY、方向脚为 IN1/IN2 常电平 + PWM 输入，需相应调整接线（本固件默认按 TB6612 的「1 PWM + 2 方向」接线）。

### 2.3 减速电机与轮系

| 项 | 型号 | 说明 |
|---|---|---|
| 主选 | **N20 减速电机 6V，带霍尔编码器** | 桌面推荐空载 100~300 RPM（按轮径选减速比） |
| 替代 | N20 3V / 12V 版 | 改电源电压即可 |
| 替代 | TT 马达（GA12-N20 / TT130） | 便宜，体积大、噪音大，履带底盘常用 |
| 替代 | JGA25-370 金属减速箱 | 扭力大，适合重负载/履带 |
| 两轮差速轮 | 橡胶/海绵轮（直径 40~65 mm）+ 万向轮（牛眼轮） | 轮径影响速度标定 |
| 麦轮 | 48 mm 麦克纳姆轮 ×4 | ⚠️ 有左旋/右旋之分，需成对购买 |

### 2.4 摄像头

| 项 | 型号 | 说明 |
|---|---|---|
| 主选 | **OV2640**（200 万，DVP 带排针） | 经典方案，固件默认 XGA |
| 主选 2 | **OV3660**（300 万，DVP 带排针） | 引脚兼容，esp32-camera 自动探测，可选 1600×1200 |
| 替代 | OV5640（500 万） | ⚠️ 需确认 esp32-camera 启用 OV5640 支持，引脚仍为 DVP |
| 不适用 | MIPI/FPC 接口摄像头 | ⚠️ 需另配 DVP 转接板，直接用不了 |

⚠️ 必须选「带排针的 DVP 模组」；FPC 软排线接口需另购转接板。

### 2.5 语音

| 项 | 型号 | 说明 |
|---|---|---|
| 麦克风主选 | **INMP441**（I2S） | 数字麦克风，信噪比高 |
| 麦克风替代 | ICS-43434、SPH0645 | ⚠️ 引脚/数据格式有差异，需改 `audio.c` |
| 功放主选 | **MAX98357A**（I2S） | D 类，直驱 3~4 Ω 喇叭 |
| 功放替代 | MAX98357（同系列，无 GAIN 脚差异小） | 基本兼容 |
| 不直接兼容 | PAM8403（模拟输入） | ⚠️ 需 DAC 或改模拟输出，固件要改 |
| 喇叭 | 3 W / 4 Ω 小口径 | 桌面音量足够 |

⚠️ INMP441 模块常带 **L/R 声道选择脚**，需接地选左声道；部分模块需额外上拉。

### 2.6 障碍感知

| 项 | 型号 | 说明 |
|---|---|---|
| TOF 主选 | **VL53L0X**（I2C，3~200 cm） | 精度高、刷新快，默认 I2C 地址 0x29 |
| TOF 替代 | VL53L1X | 量程更远（可达 4 m） |
| TOF 替代 | TOF10120（UART/I2C） | 需改驱动 |
| 超声主选 | **HC-SR04**（GPIO，2~400 cm） | 固件默认实现 |
| 超声替代 | JSN-SR04T（防水）、US-015 | 引脚兼容 |
| 机械兜底 | 微动开关/碰撞传感器 | GPIO，接触即停 |

⚠️ 多颗 VL53L0X 默认地址相同（0x29），需用 XSHUT 分时使能改地址；本方案默认 1 颗，免此问题。

### 2.7 IMU 姿态

| 项 | 型号 | 说明 |
|---|---|---|
| IMU 主选 | **MPU6050**（6 轴，I2C 0x68） | 最便宜最常见，入门首选 |
| IMU 主选 | **MPU9250**（9 轴含磁力计） | 可锁航向，飞行模式推荐 |
| IMU 替代 | ICM-42688-P / ICM-20948 | 低噪声、SPI，多旋翼常用 |

> IMU 复用 I2C 总线（GPIO41/42），与 VL53L0X（0x29）地址不冲突，AD0 接地即为 0x68。

### 2.8 电源

| 项 | 型号 | 说明 |
|---|---|---|
| 主选（方案 A） | USB 5 V / 2 A 电源 + USB 线 | 桌面常供电，最简单 |
| 方案 B | 2×18650（7.4 V）+ 7.4V→5V 降压 + 3.3V LDO + 充电板 | 可移动 |
| 必需耗材 | 100 µF + 0.1 µF 去耦电容 | 电机电源与主板电源各一组 |

### 2.9 结构与线材耗材

| 项 | 说明 |
|---|---|
| 结构件 | 亚克力板（激光切割）或 3D 打印（PLA），M3 铜柱/螺丝/螺母 |
| 线材 | 杜邦线（公-母、母-母）、22AWG 硅胶线（电机用）、双绞线 |
| 焊接耗材 | 烙铁、焊锡、热缩管、万用表 |
| 可选 | 面包板/洞洞板（原型期）、SD 卡模块（落卡存图） |

## 3. 采购注意事项（易踩坑）

1. **S3 板必须带 PSRAM**：购买时确认型号后缀（N16R8 = 16MB Flash + 8MB PSRAM）。
2. **摄像头要 DVP 带排针**：不要买 MIPI/FPC 裸排线款。
3. **INMP441 选带 L/R 脚的版本**：装配时 L/R 接地。
4. **TB6612 选带 STBY 脚的模块**。
5. **麦轮成对购买**（左旋 ×2 + 右旋 ×2），方向装反会打滑。
6. **N20 电机注意减速比**：减速比决定转速，桌面机器人选空载 100~300 RPM 级别；同款电机确认轴径（多为 3 mm D 轴）。
